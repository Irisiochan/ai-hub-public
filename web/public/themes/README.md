# AI Hub wallpaper assets

`violet-bloom.svg` and `quiet-grid.svg` are original low-contrast vector patterns
created for AI Hub. They contain no Telegram client artwork or code and are
distributed under the repository's MIT license (copyright 2026 Irisiochan).

ThemeManifest v1 can reference only these bundled asset IDs or `none`. Imported
JSON cannot supply a URL, data URI, stylesheet, or script.
